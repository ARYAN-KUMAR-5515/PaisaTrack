# PaisaTrack 💰

PaisaTrack is a smart full-stack expense management application designed to help users track income, expenses, budgets, recurring transactions, savings, and spending patterns from a single dashboard.

> 🚧 **Status:** Currently under active development.

## Features

- Income and expense tracking
- Multiple account management
- Monthly category budgets
- Budget usage and overspending alerts
- Recurring transaction management
- Spending analytics and visualizations
- Automated spending insights
- Transaction search, filtering, sorting, and pagination
- CSV transaction export
- Light and dark mode
- Secure user authentication

## Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS
- React Query
- Recharts

### Backend
- Node.js
- Express
- TypeScript
- Prisma ORM
- SQLite

### Security
- JWT authentication
- HttpOnly cookies
- CSRF protection
- Password hashing with bcrypt

## Project Goals

PaisaTrack aims to answer everyday financial questions such as:

- Where did my money go?
- How much have I spent this month?
- How much money do I have left?
- Am I exceeding my budget?
- How much am I saving?
- What spending patterns should I pay attention to?
